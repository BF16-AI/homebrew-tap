# Homebrew Tap for [bf16.ai](https://bf16.ai)

Install the official `bf16` CLI on macOS or Linux via Homebrew:

```bash
brew install BF16-AI/tap/bf16
```

## Quickstart

```bash
# Run Claude Code on uncensored 1M-context models (zero-touch launcher)
bf16 claude

# Diagnose gateway connectivity, API key & env conflicts
bf16 doctor

# Live pricing & cost estimator
bf16 models
bf16 cost main --in=500000 --out=25000 --cache=0.8
```
